A faster drop-in for make.fun's csv-reader 1.0.0: it reads broken CSV files exactly as the reference does — same columns, rows and errors on every case — about 3.7x faster than the house baseline on the practice set (210 ms vs 779 ms per 6-case set). The parser scans with native indexOf searches and slices fields out instead of reading one character at a time, while keeping every broken-row rule exact: stray CRs, unterminated quotes, quote junk, short and long rows.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
